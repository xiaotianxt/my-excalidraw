# My Excalidraw v0.1.3

Desktop-only release: no web deployment or PWA distribution.

## What's new / 更新内容

- **Drafts are not saves.** Automatic recovery never commits changes to the original file. Save explicitly with Cmd/Ctrl+S. Failed persistence blocks leaving the canvas; clear/discard checkpoints the current scene first.
- **Real previews.** Thumbnails use Excalidraw's official rendering pipeline, preserving handwritten fonts, line breaks, arrows, curves and embedded images. Old approximate SVG previews are no longer used.
- **Native desktop UI.** Custom macOS title bar with native traffic lights; file operations are also available in the system menu bar.
- **Open images.** PNG/SVG files with embedded Excalidraw data reopen as editable scenes. Ordinary images become image elements. Supported image inputs: PNG, SVG, JPEG/JFIF, WebP, GIF, BMP, AVIF and ICO; animation is not preserved. Corrupt embedded scenes report an error rather than silently flattening.
- **Editable exports.** PNG and SVG exports embed scene data by default, with an explicit opt-out. PNG defaults to **2× / 300 DPI**, with persistent preferences. Scale increases pixel dimensions; DPI only determines physical print size. SVG remains vector-based.
- **On-disk workspace.** New/explicitly saved drawings use individual disk records, avoiding the browser quota ceiling for image-heavy scenes. Legacy records stay readable and are not bulk-migrated or deleted. Renaming modifies separate labels, not drawing/image data.

## Downloads

- macOS Apple Silicon: `mac-arm64.dmg`
- macOS Intel: `mac-x64.dmg`
- Windows x64: `win-x64.exe`
- Linux x64: `.AppImage` or `.deb`
- Verify downloads against `SHA256SUMS.txt`.

## Important

- **Back up your application data and drawing files before upgrading.** Recovery drafts are not a substitute for external backups.
- Opening an image creates an independent draft; it does not bind Save to the source image. Save a drawing as `.excalidraw`, or use **Export image** to produce a new editable PNG/SVG. The source image is not automatically overwritten.
- Embedded exports contain editable scene data and images, not just visible pixels. Disable scene embedding when you want only an image.
- PNG exports are limited to 32 million pixels / 16384 pixels per edge; lower the scale or choose SVG for larger scenes. Image imports are capped at 64 MB.
- **Hosted installers are not signed with a distribution certificate or Apple notarized.** No signing credentials are configured in CI. OS trust prompts may appear; do not disable platform security globally. Local developer-signed builds are separate from these hosted artifacts.
- Recovery checkpoints are retained until you manage them explicitly.
